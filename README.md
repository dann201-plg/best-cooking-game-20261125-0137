Warung Kilat is a fast Indonesian street-food cooking game. Orders roll in on the ticket board — nasi goreng, mie ayam, sate ayam, ayam geprek — each with a spice level that changes its recipe. Click the ingredient bins (or press 1-8) to build each dish on its plate, then hit SAJI before the customer's patience runs out. Combos, a rush-hour surge and a 150-second shift keep the pressure on. It runs offline in a desktop browser from static files, with synthesized sound effects and no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Click the ingredient bins (or press 1-8), select a plate with Q/W/E, serve with Space or the SAJI button, clear a plate with X.
